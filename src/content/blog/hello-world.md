为什么要写博客？这是我在搭建这个网站之前问自己最多的问题。

在这个信息爆炸的时代，每天都有无数的文章、视频、播客在争夺我们的注意力。写博客似乎是一件"过时"的事情。但恰恰相反，我认为博客的价值从未消减——甚至在 AI 时代变得更加重要。

## 输出是最好的学习

费曼学习法告诉我们：如果你不能用简单的语言解释一件事，说明你还没有真正理解它。写博客就是最好的费曼实践。当你试图把一个技术概念写清楚的时候，你会发现自己对它的理解远远不够。

```
# 一个简单的 Python 例子
def fibonacci(n: int) -> int:
    """Calculate the nth Fibonacci number."""
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)
```

## 建立个人品牌

在技术社区，一个好的博客就是你的名片。当别人搜索你的名字时，他们能找到你的思考、你的项目、你的成长轨迹。这比任何简历都有说服力。

## 记录成长

回头看一年前的自己，你会发现你已经走了很远。博客就是那个时间胶囊，记录着你的每一个里程碑。

所以，如果你也在犹豫要不要开始写博客——**现在就开始吧**。不需要完美，不需要面面俱到，只需要把你知道的东西分享出来。这个世界会因为你的分享而变得更好一点。
